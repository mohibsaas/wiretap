# Security Policy

## Supported versions

Report vulnerabilities against the latest `main` branch. We do not maintain long-lived release branches yet.

## Reporting a vulnerability

**Do not open a public GitHub issue for security reports.**

Please use [GitHub Private Vulnerability Reporting](https://github.com/mohibsaas/wiretap/security/advisories/new) on this repository, or email the maintainers listed in the commit history / GitHub org.

Include:

- A short description of the issue
- Steps to reproduce (PoC if possible)
- Impact (e.g. secret leakage, local file access, RCE)
- Affected commit / version if known

We will acknowledge reports as soon as we can and coordinate a fix before any public disclosure.

## Non-security bugs

Use GitHub Issues for crashes, incorrect scores, UI bugs, and feature requests.
